# SKU 可选商品参数

买家详情的规格默认两排，超过四项显示“展开全部规格”，点击后可收起。原演示参数卡和硬编码参数已移除。

商家在商品的“规格与库存”中，展开对应 SKU 的“商品参数（选填）”，每行填写 `名称：内容`，与该行规格一起保存。最多12项，名称24字，内容100字。可留空或清空，不影响正常销售。新建SKU可先正常添加，再选填参数。

买家悬停或键盘聚焦对应规格时显示该SKU真实售价与库存，并附加商家配置的参数；没配置时只显示售价库存，不补造材质、容量。移除了仅显示SKU名称的原生title提示。全部文案使用DOM文本渲染。参数通过既有SKU创建/更新API传递 `parameters: [{name, value}]`，空数组清空，省略字段保持原值。只有所属店铺商家可修改，买家只能读取。

数据保存在独立 `sku_parameter_profiles` 表，应用正常启动的 `Base.metadata.create_all` 自动创建，无需修改旧SKU列。无参数旧商品返回空数组，不自动填充示例。

本轮新进程预览入口为 `http://127.0.0.1:8001`，8000旧进程未重启，尚未加载参数API；旧API页面会明确提示后台需要重启而禁用参数输入。前端展开/移除卡片刷新即可生效。
