# Agent操作能力 PRD

日期：2026-10-20。状态：开发基线。目标：买家从推荐直接完成选规格、加购和进入结算；商家通过自然语言生成完整商品配置，预览后保存为商品草稿。

## 可行性与工作量

可行。买家已有quickBuy、购物车和结算，主要补推荐卡入口、实时读取和交互保护，改动较小。商家需要新增结构化商品提案、持久化、确认接口、幂等、鉴权及预览界面，复杂度中等。让模型直接上架、批量改价、支付或退款则需要额外审批、并发版本校验和补偿，作为后续阶段。

## 产品原则

模型生成方案，用户通过明确按钮确认业务写入。模型没有确认接口工具，也不能传入用户或店铺身份。查询与提案工具和最终执行端点分离。所有价格、数量、库存、归属在服务端校验。买家推荐不自动加购；立即购买仅进入已有结算，不自动付款。

## 本期范围

### 买家

推荐与商品搜索卡保留查看详情，旁边提供购物车按钮，包含可读的无障碍名称。点击重新读取当前店铺商品详情，成功后打开已有购买小窗，选择SKU和数量，显示实时售价和库存。点击加入购物车使用现有API；立即购买进入现有结算页。无登录触发登录，商品已下架/禁售/店铺停业时显示服务端错误。卡片加载和加购进行中禁止重复点击，失败可重试；切换身份或店铺后丢弃旧请求，不写入旧账号。恢复的聊天卡也采用同样入口。

### 商家

新增商品配置意图及prepare_product_draft工具。支持从自然语言生成名称、分类、简介、图片路径、限购和多个SKU（规格、价格、库存）；也支持以本店现有商品为模板复制成新草稿。来源商品只允许本店，复制不覆盖原商品，不复制销量或交易数据。名称缺失、非法价格和规格等由参数校验反馈；工具不擅自生成供应商保证、认证或真实照片。未提供的价格库存不得自行估算，缺必需条件先询问。

提案存数据库，绑定当前商家、店铺、会话，默认15分钟有效。助手回复显示待确认卡，点击预览读取服务端提案而不是执行模型文本。预览完整字段，支持取消或确认保存草稿；编辑与上架复用原商品编辑页。确认后返回新商品链接，草稿不可在买家端购买。提案可撤销，过期不可执行。同一提案多次确认只能返回同一个商品，创建草稿和提案完成状态同事务提交；失败回滚，可重试。生成提案本身不创建业务商品。

## API与数据

新增agent_product_proposals表：不可猜测ID、user_id/shop_id/session_id、payload、状态、created_at/expires_at、product_id。模型工具只生成pending提案。商家鉴权API提供GET详情、POST confirm、POST cancel；仅同用户同店铺可操作，买家403，其他商家404。完成与取消状态保留作操作记录。确认不接受客户端替换商品配置；修改方案重新生成提案或进入商品编辑页。

## 扩展规划

下一阶段：对本店既有商品生成修改差异，绑定商品版本，冲突重新预览；补货/改价/上下架按风险提供单次与批量确认。买家支持对话生成购物清单、选择多件后统一结算；售后生成申请草稿，确认后提交。涉及资金或不可逆操作继续保留独立确认，不直接暴露通用SQL、任意HTTP或通用写工具。

## 验收

1. 推荐卡与恢复卡能打开真实SKU购买窗；正常加购与进入结算成功，取消不写业务。
2. 卡片后商品下架、价格库存变化时读取最新数据；失败提示清楚。
3. 重复点击与账号/店铺切换不能重复提交或错写身份。
4. 商家自然语言调用提案工具，先显示预览；确认前商品数不变，确认后仅新增draft。
5. 非本店来源、买家调用、跨商家读取/确认/撤销全部拒绝。
6. 重复确认返回同一商品；过期/撤销不能确认；SKU校验失败不创建商品；异常回滚不遗留执行中状态。
7. 可控模型测试验证工具接入，接口测试验证生命周期与权限，Node/浏览器验证交互，现有回归通过。真实模型验收单独报告，不能以模拟结果替代。

## 本期不包含

真实支付渠道、Agent自动付款退款、直接覆盖既有商品、批量无人值守上架和跨店商品配置。本期采用完整商品草稿确认闭环，上架继续走已有商品管理流程。


## 对话操作与服务入口补充（2026-10-20）

- 每张买家商品卡在对话中询问是否加入购物车，提供“选规格并加购”“暂时不需要”；前者复用真实SKU弹窗，仍可选择立即购买，后者只收起询问、不写入业务。
- 买家助手快捷入口为查本人订单、订单中心、物流、联系商家和申请售后；商家助手为本店订单、订单管理、发货物流、客户消息、售后处理、商品配置、库存预警和经营概览。
- 订单回答按订单号提供查看、物流、关联订单沟通和售后入口，真正读取及处理仍经服务端资源归属校验。沟通不自动发送消息。
- C端人工联系入口置于顶部快捷导航最右侧，独立描边框，点击后打开原服务弹窗；不再显示底部人工联系悬浮按钮。B端客户服务入口保持商家用途。
- 验收覆盖角色菜单差异、显式加购及取消、顶部位置、物流/售后切换、关联订单沟通、账号与店铺切换隔离。
