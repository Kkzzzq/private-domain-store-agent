# 南枝手作 UI 素材与落地清单

整理日期：2026-10-19。范围：现有原生 HTML / CSS / JavaScript 商城与商家工作台。本文为后续改版选材，不代表已经替换业务页面；预览见 `/ui-materials.html`。

## 1. 选材方向

- 保留两端一致的米白底、暖灰文字、低饱和陶土色。背景建议 #F7F3EC，卡片 #FFFCF7，边框 #E5DDD2，正文 #3D3935，主按钮 #98543F。浅色用于底，不把正文和按钮文字也一起变淡；实际组合需检验对比度。
- 原生页面优先局部引入 SVG 和 CSS，不为换皮迁移 React/Vue，不整包叠加多个组件库。
- 商品照片统一自然光、米色背景、无水印，SKU 图必须对应实际颜色与款式。不能拿不同杯子的照片当同款规格实拍。
- GitHub 星标不是素材授权，也不是审美标准；以下按适配程度选用，不沿用未核实的星标数字。

## 2. 可直接选材的来源

### 图标与按钮组件

- [Tabler Icons](https://tabler.io/icons)：首选线性图标。购物袋、搜索、收藏、订单、物流、设置、对话等统一使用一个集合；建议 20/24px、同一描边粗细。SVG 可按需本地保存，保留 [MIT 许可](https://tabler.io/license)。只选择免费图标，不把该站邮件模板、插画等其他产品视作同样授权。
- [Tabler Admin](https://github.com/tabler/tabler)：参考后台卡片、筛选栏、表格、分页、表单、状态提示；开源管理模板 MIT，导入代码需保留对应声明。当前只借鉴布局，不直接加载全套 Bootstrap 以免覆盖既有 CSS。
- [Web Awesome](https://github.com/shoelace-style/webawesome)：项目已有 Web Components 依赖，优先复用已有按钮、输入框、弹窗等能力；免费开源部分和 Pro 分开核对，不将收费组件截图当免费素材。
- 按钮不是 PNG 图片：用 CSS 实现默认、悬停、键盘聚焦、按下、禁用、提交中六种状态。图标按钮必须有可访问名称；禁用动作需要说明原因。

### 字体与排版

- [思源黑体 Source Han Sans](https://github.com/adobe-fonts/source-han-sans)：中文正文/后台适用；[SIL OFL 1.1 许可](https://github.com/adobe-fonts/source-han-sans/blob/master/LICENSE.txt)，分发字体须附带版权与许可，修改版注意保留名称限制。
- 不先下载完整庞大 CJK 字库。正文先用系统中文无衬线字体栈，品牌标题少量使用系统宋体；如后续引入字体，选实际使用的字重并做合规子集化。
- 正文 14–16px、行高 1.6；辅助文字不少于 12px；金额数字对齐；不使用整页粗体、过多英文字母间距或图片文字。

## 3. 用户提供项目如何参考

- [Medusa Storefront](https://github.com/medusajs/nextjs-starter-medusa)：看商品列表、详情、购物袋和结算信息层级；它是 Next.js 前端，不能直接粘进当前原生页面，照片许可需另查。
- [Ant Design Pro](https://github.com/ant-design/ant-design-pro)：看复杂后台筛选、批量操作、错误提示；只参考交互，不把 React/Umi 依赖引入当前项目。
- [mall](https://github.com/macrozheng/mall)、[newbee-mall](https://github.com/newbee-ltd/newbee-mall)：看业务流程、商品/SKU 和订单信息，不直接搬 Java 后端。仓库代码与演示商品图授权分别核对。
- Saleor、vue-element-admin、AdminLTE、ngx-admin、eladmin、Gentelella 暂不作为本轮主要素材库：避免多个体系混用。若复制某仓库具体组件，先核验该版本 LICENSE、资源来源及依赖，不依据“开源”两个字默认可复制。

## 4. 页面全覆盖清单

- 全局：店铺字标/ favicon、顶部导航、面包屑、分类、搜索、分页、页脚、移动导航；图标统一，不继续混用彩色 emoji。品牌字标暂用自有文字，不借用他人 logo。
- 首页：场景横幅、分类图片、推荐商品、商品卡、价格、折扣和缺货状态；推荐区保留真实商品接口，禁止静态装饰价格冒充实时数据。
- 商品详情：主图/缩略图、放大、SKU、数量步进、库存提示、收藏、加购、购买、规格表、售后说明；规格禁用与选择态清晰区分。
- 交易：购物车空态/列表/失效项、地址表单、费用明细、提交中、订单成功/失败/取消、物流与售后入口；模拟支付须继续明确标识。
- 用户：登录/注册/退出、表单校验、我的订单、订单筛选、个人资料和地址管理；不靠颜色单独表达错误。
- 商家：侧栏、概览指标、真实数据图表、商品与 SKU 编辑、上下架、库存预警、订单表、分页、分类标签、装修上传与店铺设置。
- AI：右下角入口、展开/收起、问题建议、输入中、工具执行中、商品推荐卡、来源引用、重试、清空会话、错误与降级提示；不得将降级结果伪装成真实模型调用。
- 系统状态：首次加载骨架、无商品、无搜索结果、无订单、无权限、登录过期、网络错误、图片失败、保存成功和删除确认；空态使用轻量自制 SVG/排版，避免不明许可插画。

## 5. 可直接采用的原创中文文案

- 首页标题：把喜欢的日常，慢慢带回家。辅助：看看布艺、陶器和生活小物，找到适合自己的那一件。
- 搜索：搜索商品、材质或用途。空结果：暂时没找到合适的商品，试试更换关键词或清除筛选。动作：清除筛选。
- 商品：选择规格 / 加入购物车 / 立即购买 / 暂时缺货 / 到货后再看看。库存和价格只能填实际接口值，不写虚假稀缺提示。
- 购物车：购物车还是空的，去挑一件喜欢的小物吧。动作：去逛逛。
- 提交：正在提交，请稍候…；成功：已保存；失败：保存失败，已保留你的填写内容，请重试。只有真正保留表单内容时才能用后一句。
- 订单：还没有相关订单；登录过期：登录已过期，重新登录后继续查看。支付：演示支付，不会产生真实扣款。
- 买家 AI：告诉我预算、用途和偏好，我帮你看看本店有哪些选择。建议：100 元以内买两件 / 哪款适合送礼 / 查询我的订单。
- 商家 AI：可以帮你查看本店商品、库存、订单和经营概况。建议：查看库存预警 / 今天有哪些待发货订单。没有对应日期筛选能力时不要提供无法执行的建议。
- AI 等待：正在查看相关商品…；无候选：目前没有同时满足这些条件的商品，要不要调整预算或偏好？；知识不足：暂未找到明确依据，请联系商家确认。
- 危险操作：确定下架这件商品吗？下架后买家将无法购买。动作：暂不下架 / 确认下架。不得把“下架”写成“删除”。

## 6. 落地顺序与验收

1. 先统一色板、字号、按钮/表单状态与图标，去掉 emoji 混搭；不改变业务权限和接口。
2. 再逐个商品核对主图、SKU 图与文案，补齐作者和许可清单；商用真实商品优先商家实拍。
3. 然后整理首页/详情/购物车与后台表格信息层级，最后完善 AI 卡片、空态与错误态。
4. 在 360、768、1440px 验收：无横向溢出、键盘可访问、焦点可见、按钮文字对比度达标；普通正文至少 4.5:1，大字号至少 3:1，触控目标建议 44px。
5. 资产登记必填：本地路径、具体来源页、作者、许可页、下载日期、修改记录、用途、审核人。当前新增候选照片尚未下载/绑定业务商品，不能标记为素材上线完成。
