## 验证结果

完整测试：80 passed。包含原有 63 项与新增 17 项。新增覆盖双端权限、跨用户与跨店订单隔离、推荐可见性/预算、会话隔离、限流、参数篡改、重试、模拟 Function Calling、模型降级、订单追问、结构分块、摘要预算、真实 Chroma 持久化与向量生成失败保留。

执行：backend 目录 `python -m pytest -q --basetemp data/pytest-<唯一目录>`。本机默认系统临时目录存在权限错误，所以使用项目 data 下独立目录；该目录被 Git 忽略。`node --check web/b.js`、`node --check web/c.js`、Python compileall、pip check 通过。

本地 FastAPI 服务已运行；浏览器商家经营概览返回真实本店数据，模型不可用时显示规则查询模式。测试数据使用 SQLite 与内存 Redis；Chroma 测试使用确定性测试向量，聊天模型测试使用模拟对象。

浏览器买家预算 40 元推荐返回 32/38/36 元三件商品，卡片图片正常显示，点击 32 元笔记本进入本店详情，价格一致。后台输入/对话布局、新对话和发送禁用状态已目视核对。
