# Agent操作验收记录

日期：2026-10-20。需求：[PRD](prd-agent-actions.md)。

## 已实现

- 买家搜索/推荐及恢复聊天卡增加购物车按钮，先读取最新商品详情，再复用规格弹窗、购物车和结算；校验身份/店铺切换、重复点击与缺货规格。
- 商家通过prepare_product_draft创建15分钟有效提案，绑定用户、店铺和会话。支持明确商品配置和本店商品复制模板，预览确认后仅新增draft；原商品不覆盖。后续编辑及上架复用商品管理。
- 业务确认端点不是模型工具。提案原子领取与草稿插入同事务，重复确认返回同一商品；取消、过期和跨身份拒绝执行，失败回滚。

## 验证证据

- 新增8项后端测试通过：未确认不创建、确认幂等、取消/过期、买家与跨用户权限、复制不改原商品、非法参数/身份、失败回滚、可控模型编排，以及独立SQLite文件与两个数据库会话并发确认只创建一个商品。多项断言合并在同一个测试函数中；没有宣称完成MySQL并发压测。
- Node行为测试覆盖缺货切换、重复加购、请求前后账号切换、商品卡实时读取和旧响应隔离。既有Node回归与前端语法检查通过。
- 真实GLM-5.3-Flash在独立SQLite库和内存Redis环境提取两规格售价库存，实际调用prepare_product_draft；确认前商品数不变，确认后draft、再次确认同ID。报告backend/data/acceptance/real-agent-action.json。这是单场景真实模型验收，未覆盖全部自然语言表达，也不是MySQL/Redis全链路验收。
- 隔离18079浏览器：买家搜索马克杯→购买按钮→SKU弹窗→加购；商家通过本地模型协议fixture生成提案→预览→确认→草稿编辑页，白色37元/库存12，蓝色39元/库存8。截图backend/data/acceptance/agent-product-confirmed.png。此UI验收与上述真实模型测试分别记录。
- 所有业务写验证均在隔离数据库，不创建真实线上商品、订单或付款。

- 冻结暂存区独立发布快照：后端全量260 passed（231.92秒）；最终暂存区前端另行提取后通过语法与新增Node行为测试，未混入认证与统一账号并行工作。

## 后续范围

当前生成草稿，不直接修改既有商品，不自动上架、支付或退款。图片与未提供字段可在草稿中补充；复制模板不复制商品标签、销量或交易数据。同一提案幂等，不对不同提案进行内容去重。商家待确认入口暂保留在当前页面聊天内存，刷新后不恢复按钮；未确认的提案15分钟后不可执行，可重新生成。后续可以增加提案记录列表与版本差异确认。
