## 本轮复现并修复

### RE03：用例导航缺陷

报告页按小时分组，默认收起。旧用例直接点击首个 `[data-run-id]` 内按钮，没有先展开所属分组；Playwright 正确等待可见性后超时。不是报告打不开，也不应通过强制点击绕过。

修复：复用 `browser_extra.first_report_row`，等待分组出现，必要时正常点击标题展开，再等待报告行可见并打开报告。覆盖分组已展开与收起两种情况，其他旧分组不受影响。

原始运行 `b598847b5ebc41528341fddde8c2f820` 保留。

### RA06：业务 Agent 拒绝路径缺陷

跨店注入问题含“忽略你的规则”，先前被分类成政策问题。模型拒绝越权而不调用工具时，程序仍要求政策工具，纠正后继续拒绝便触发规则兜底。RA06 要求真实模型，因此判失败是正确的，不应放宽用例接受 fallback。

修复：明确跨店数据请求单独路由，无论买家还是商家均不提供数据工具，并在模型上下文要求礼貌拒绝；正常拒绝不触发“缺少业务工具”错误。保留真实模型调用；模型实际不可用时仍不算真实模型验收通过。“不要搜索其他店铺，只搜索本店”不进入该拒绝路由，正常本店查询仍要求事实工具。

原始运行 `5963a99b4f9e46189cb7715c1fa1def7` 保留。
