# 后台紧凑布局与标签独立配色

## 页面交互

- 分类与商品标签：文字列表；顶部新增；弹窗编辑。商品标签提供背景、边框、文字三种颜色和即时预览。
- 商品：保留筛选、分页与SKU按需展开；普通点击新增、编辑打开基本信息弹窗；直接访问商品编辑链接仍支持完整编辑页。
- 订单：保留业务列表、筛选、批量发货及原有详情弹窗，不增加无意义的常驻表单。
- 首页装修：轮播、商品栏目、反馈均保留紧凑列表，新增、编辑使用弹窗；栏目可编辑标题、副标题、来源与商品。
- 首页样式与店铺设置：默认显示配置摘要，点击编辑再展开表单。复杂外观表单在弹窗内部滚动。
- 优惠券：仅显示已发放列表，创建表单移入弹窗；已发放券规则仍不可修改，只能启停。
- 配置页最大宽1160px，商品与订单工作区最大1400px；保留米白色主题。

## 数据兼容

新增独立表 `product_tag_styles`，按标签ID保存 `background_color`、`border_color`、`text_color`。启动时通过既有建表流程创建，不改旧标签字段或覆盖商家颜色。

旧标签没有独立配色时，仍按原主题色推导浅背景、浅边框和深文字。PATCH省略颜色不修改，空字符串恢复该项自动推导。颜色值只接受六位HEX或空字符串；商家权限与店铺隔离沿用原标签接口。

三种颜色经同一标签序列化返回B端及C端商品列表、详情和首页。前端统一通过 `applyTagStyle` 设置CSS变量，预览与商品角标复用同一套样式。
