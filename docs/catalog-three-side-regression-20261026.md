# 商品三端展示与按钮回归（2026-10-26）

## 结论与范围

对 SPU / SKU / C 商品宽表改造后的真实站点执行接口、浏览器与数据库对照。
检查包含 C 首页/合集/详情/规格选择/搜索/购物车/结算/订单/历史、B 商品编辑/规格排序/价格库存保存/草稿状态，以及 OP 查询/完整维护/禁售与解除。
支付和物流按项目现有演示流程验证，不表示接入外部支付或快递服务。

## 实际发现与修复

1. B 与 OP 共享的 SKU 保存按钮引用了已经移除的 `parameterInput`。真实页面点击出现 `parameterInput is not defined`，没有发出 PATCH。移除该失效引用，保存价格库存时保留原有参数。
2. 新的 SPU 业务编号未用于 B 列表搜索、OP 商品查询和页面展示。补齐两端编号显示与搜索，保留内部 ID 查询，并防止超长数字搜索造成整数溢出。
3. C 浏览记录在全部规格下架后丢失最低价，页面可能显示 ¥0；划线价也可能取自另一规格。改为保留可用展示价格，并让现价和划线价对应同一 SKU；标注“暂无在售规格”。
4. 失效购物车商品仍有可点击的数量按钮和无效详情链接。数量按钮、详情链接和结算按可购买状态处理，仍允许删除；可购买商品的数量边界同时受库存与 20 件上限约束。

5. 手机购物车原先只减少网格列数，价格、数量与删除按钮被自动排入过窄列。明确各元素位置，并增加真实浏览器矩形重叠断言。

6. 商品未设置图片时，主图预览使用空 src 显示破图；规格图的 empty 样式继承了通用空态内边距，撑高整行。改为隐藏空主图预览并去掉规格空图额外内边距，增加真实尺寸断言。

修改了相关静态资源版本，避免已打开页面继续使用缓存旧脚本。
