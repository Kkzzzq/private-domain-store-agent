# 三个 Agent 全量建设：需求方案

版本：2026-10-20。本文是后续实施基线；已实现能力以运行证据为准，不以设计文字为准。

## 1. 产品目标与边界

形成业务服务、业务助手评测、业务功能验证三个独立职责闭环。业务 Agent 服务商家和买家；两个测试 Agent 只服务 OP。OP 展示三个 Agent 的能力、版本、测试和报告，不把测试入口暴露给商家或买家，不把业务助手搬离 B/C。

OP 侧栏独立设置“Agent 与测试中心”，与运营管理、管理与审计同级。最终包含：三个 Agent 总览、业务 Agent 能力与版本、业务 Agent 评测、业务功能测试、用例与数据集、运行与报告。助手调用的运营审计仍属于管理与审计；测试调用轨迹属于测试报告，两者按关联 ID 串联而不是混放。

## 2. 业务 Agent 需求

- 买家：先读取当前店铺可售目录，再提取用途、预算、材质、数量等条件；缺关键条件先澄清；推荐给出商品/SKU、实时价格库存、选择依据和不匹配项。组合推荐校验总价而非只校验单价。无匹配如实回答。
- 多轮：支持“第二个”“预算改为100”“这个还有蓝色吗”等追问；记住实体与约束，不把其他用户、店铺或新会话的历史带入。
- 查询：商品搜索、SKU 库存、本人订单、物流、售后政策；商家额外有本店概览、库存预警及已有受控提案能力。付款、退款等越权动作拒绝；写提案必须预览和确认，重复确认幂等。
- 知识：商品说明、平台规则、售后政策清洗分块，经真实 Embedding 存入 Chroma；回答引用来源、知识版本。无命中不编造，冲突政策明确提示。
- 体验：完整答案一次返回，不分批输出；等待提示使用店铺固定 AI 名；支持安全文字渲染。快速路径与真实模型路径分别记录，快速返回不能伪装 Function Calling。
- 安全：身份和店铺范围由服务端注入，模型参数不能覆盖；参数验证、有限重试、输出异常处理、供应商切换均留下脱敏轨迹。

## 3. 业务 Agent 评测 Agent

对象是上述业务 Agent，不是让业务 Agent 自己给自己评分。OP 选择目标版本、规则/真实模型模式、数据集与预算，生成计划，人工批准后执行。

覆盖既有 A01—A40：目录推荐、多轮、预算、订单隔离、RAG、知识更新与冲突、注入防护、错误重试、提案与确认、模型切换、长会话。每条用例必须有前置数据、输入轮次、业务事实、工具预期、硬断言、清理条件。真实模式必须证明模型调用及工具/检索执行，不得把 mock 或兜底算真实通过。

## 4. 业务功能测试 Agent

对象是接口、业务状态及 B/C 页面，不依赖业务 Agent 才能执行。覆盖既有 F01—F30：登录授权、商品状态、SKU 同步、购物车限购、金额运费、优惠券、库存与并发、订单、装修、评价、物流售后和提案事务。

采用固定白名单执行能力；AI 可选用例、解释失败，不能自行运行任意命令、SQL、URL 或生成的测试代码。补充浏览器端到端：登录→商品规格→加购→用券结算→订单查询，商家改 SKU 顺序/装修发布→买家显示一致。页面证据与接口证据分别保存。

## 5. 联合运行与可视化

三个 Agent 总览显示职责、实际接入能力、版本及最近验收，不用一个绿色状态掩盖未接入项。联合运行先功能回归，再业务 Agent 评测，各自独立数据副本、会话、预算及结论；不计算混合通过率。

报告三栏：用例与步骤、请求/对话/工具/检索证据、可信事实与断言。状态区分通过、失败、阻塞、取消、未接入。支持取消、保留原记录的重跑、脱敏导出、按版本比较。未执行、无证据、清理失败、依赖不可用均不能通过。

## 6. 环境、权限与非功能验收

- OP 身份与质量权限双重校验，撤权后停止后续步骤；普通 B/C 访问 API 返回拒绝。
- 合成快速档和真实依赖档分开统计。真实依赖档必须是专用 MySQL 数据库、Redis 命名空间、Chroma 目录，不连接现有业务库执行写测试。
- 设置模型调用次数、tokens、超时预算；超额停止，未知费用标记估算。不得无限重试消耗余额。
- 性能记录端到端与各阶段 p50/p95、缓存命中、错误率；本地固定数据集至少20次热/冷对照后确定目标，不预填虚构性能值。
- 先通过所有关键权限/金额/库存硬断言，再讨论语义评分；模型裁判不得覆盖安全失败。

1. 需求阶段：本文件与旧40A/30F明细保持一致，补齐每项验收定义。

3. 实现阶段：先导航和能力台账，再补功能用例，随后助手场景与业务缺陷，最后真实依赖、E2E和联合验收。
4. 总验收：40A/30F全部有可执行适配与独立断言；真实模型、真实 RAG、真实业务 MySQL/Redis各有运行证据；全部关键项通过，其他失败显式列出。代码已写、用例已登记、真实验收通过必须分别统计。
