# 千问统一模型配置

当前聊天配置统一使用阿里云百炼 OpenAI 兼容端点：
`https://dashscope.aliyuncs.com/compatible-mode/v1`，模型 `qwen-flash`，供应商样式 `qwen`，关闭思考模式。

业务助手的 `CLOUD_*`、功能规划/评测的 `QA_CHAT_*`、被测业务助手的 `QA_TARGET_CHAT_*` 均显式配置为同一模型；清空旧聊天候选模型，避免发生隐式跨供应商回退。
现有 DeepSeek / 智谱适配器和历史测试证据继续保留，但不属于当前启用配置。

密钥通过各配置的 `*_API_KEY_FILE` 引用仓库外文件，本机与服务器使用各自的绝对路径。不要把密钥内容提交到仓库或放进前端。
`.env.example` 仅给出占位路径，真实 `.env` 不提交。

向量检索仍使用专用千问 embedding 模型，不能把聊天模型 `qwen-flash` 当成 embedding 模型。
本次切换也将向量与图像检索凭据指向同一新账号；原向量模型与维度保持不变，已有索引不因密钥切换而更换模型。

普通单元测试显式清空 QA 聊天与被测模型覆盖，避免读取本机真实配置后产生意外网络调用；真实模型验收则使用正式受控执行入口。

验收需要同时确认配置、真实聊天、原生工具调用，以及业务真实模型结果 `mode=llm`；规则回退不算真实模型通过。旧 HTTP 402 失败报告保留，通过新报告证明切换后的结果。

搜索允许模型省略商品名的装饰标点，但仍匹配完整词语和编号。推荐关键词保持 AND 语义；空结果会说明本次必含词，提醒模型区分“任选一种”与“同时满足”，不自动放宽预算、库存或排除条件。
